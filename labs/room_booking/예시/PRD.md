# 회의실 예약 페이지 — PRD (MVP)

## 1. 목표
날짜별 회의실 3곳의 예약 현황을 한 화면에서 보고, 겹치지 않게 예약 · 취소한다.

## 2. MVP 범위
| 포함 | 제외 (다음 버전) |
|---|---|
| 날짜 선택 · 시간표 보기 | 로그인 |
| 예약 추가 · 취소 | 팀원 간 공유 (서버 저장) |
| 겹치는 예약 막기 | 슬랙 알림 · 반복 예약 |

## 3. 기능 명세
- F1 날짜 선택: 기본값 오늘 · 이전 / 다음 날 버튼
- F2 시간표: 회의실 3열 × 09:00~18:00, 30분 칸
- F3 예약 추가: 빈 칸 클릭 → 예약 창 (이름 · 회의 이름 · 시작 · 끝)
- F4 겹침 막기: 같은 회의실 · 겹치는 시간이면 저장하지 않고 「이미 예약된 시간」 표시
- F5 예약 취소: 예약 칸 클릭 → 상세 → 취소

## 4. 화면별 요소
- 시간표: 상단 날짜 · 화살표 / 회의실 이름 3개 / 시간 줄 / 예약 칸(회의 이름 · 이름)
- 예약 창: 입력 4개 · 저장 · 닫기 · 오류 문구 자리

## 5. 데이터 항목
| 항목 | 예 |
|---|---|
| 회의실 | 대회의실 |
| 날짜 | 2026-11-20 |
| 시작 · 끝 | 14:00 · 15:00 |
| 이름 | 김하늘 |
| 회의 이름 | 주간 회의 |

저장: 브라우저 localStorage (MVP)

## 6. 완료 기준
- [ ] 오늘 날짜 시간표가 첫 화면에 보인다
- [ ] 대회의실 14:00~15:00 예약 후 새로고침해도 남아 있다
- [ ] 같은 회의실 14:30~15:30 예약은 막힌다
- [ ] 예약을 취소하면 칸이 비워진다
- [ ] 모바일 폭(390px)에서도 가로 스크롤 없이 보인다
