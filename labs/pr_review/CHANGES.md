# 이번 변경 (PR #142) · 운송비 정산 검증 기능

- src/settle.js: 정산액 계산 · 청구액 검증 (1% 넘게 다르면 이의 제기)
- src/db.js: 운송사별 청구 내역 조회
- src/config.js: 외부 단가 API 연결 설정
- src/report.js: 이의 제기 목록 보고서
- test/settle.test.js: 계산 · 판정 테스트

정산 기준: 정산액 = 거리 × 중량 × 톤km 단가, **원 미만 절사** · 청구액과 정산액 차이가 **1%를 넘으면** 이의 제기 (정확히 1%는 정상)
