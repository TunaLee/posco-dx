# 하네스 엔지니어링 실습

> ※ 회사(「한빛스틸」) · 강종 · 규격 · 시험 결과는 모두 실습용 가상 자료입니다.

준비된 것은 **데이터(가상 시험실 시뮬레이터)뿐**이다. 앱은 Claude Code 와 함께 처음부터 만들고, 실습마다 탭이 하나씩 늘어난다.

## 준비 (한 번만)

1. **Claude Code 설치 · 로그인** — 회사 Business(Team) 계정. 확인: `claude --version` · `claude auth status`
2. **Python 3.10 이상** — 표준 라이브러리만 쓴다. 설치할 패키지 없음.
3. VS Code 로 `steel_qc/` 를 열고 가상 시험실을 켠다: `python sim/lims_sim.py` (Windows 는 `py`)

- 터미널에 `ANTHROPIC_API_KEY` 가 있으면 API 요금으로 돈다. 회사 계정으로 돌리려면 비워 둔다.
