# 불합격 보고 절차

1. `mcp__lims__reject_summary` 로 이상 건만 받는다. 합격 건은 개수만 쓴다.
2. 불합격 코일마다 `mcp__lims__coil_detail` 로 값과 판정 근거를 확인한다.
3. 규격이 헷갈리면 `mcp__lims__get_spec` 으로 확인한다. 기억으로 쓰지 않는다.
4. 원인 추정이 필요하면 `investigator` Agent 에게 맡기고 결과만 받는다.
5. 아래 형식으로 `out/불합격보고.md` 에 저장하고, 대화에는 세 줄만 답한다.

## 형식
- 요약 한 줄: 검사 N건 · 불합격 N건 · 근접 N건
- 표: 코일 · 강종 · 라인 · 이탈 항목 (값 / 규격) · 조치 제안
- 근거 없는 원인은 「확인 필요」
- 출하 승인은 쓰지 않는다 (사람이 한다)
