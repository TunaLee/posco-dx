# 한빛스틸 코일 품질 판정 (실습용 가상 자료)

## 판정 기준
- 규격: 시뮬레이터 `/api/specs` (= `sim/specs.json`) 의 강종별 하한 · 상한
- 한 항목이라도 범위를 벗어나면 **불합격**, 한계값의 3% 안쪽이면 **근접**, 나머지 **합격**
- 한계값과 같으면 범위 안

## 화면 — 코일 품질 콘솔
- `python app/server.py` → http://127.0.0.1:8810
- 탭 하나 = `app/tabs/` 의 HTML 파일 하나 · 이름은 `번호_이름.html` (다음 번호로) · `<title>` 이 탭 이름
- 탭은 `/sim/...`(시뮬레이터) · `/files/data/...` · `/files/out/...` 만 읽는다 · `01_시험결과.html` 과 같은 모양
- `app/server.py` · `app/index.html` 은 고치지 않는다

## 파일 위치
- 기록(JSON · JSONL): `data/` · 보고서(Markdown): `out/보고서/` · `out/조사/` · `out/통보/`
- 코드: 판정 `judge.py` · MCP 서버 `mcp/` · Hook `hooks/` · 기능 `reports/` · 테스트 `tests/`
- 파이썬 표준 라이브러리만 · 외부 패키지 설치 안 함

## 답 형식
- 표: 코일 · 강종 · 판정 · 이탈 또는 근접 항목 (값 / 규격) · 불합격을 맨 위에
- 근거 없는 추정 금지 · 모르면 「확인 필요」

## 하지 않는 것
- 출하 승인은 사람이 한다 · 승인 도구는 부르지 않는다
- `sim/` 은 고치지 않는다
