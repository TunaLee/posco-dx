# 한빛스틸 코일 품질 판정 (실습용 가상 자료)

## 판정 기준
- 규격: `sim/specs.json` 의 강종별 하한 · 상한 (한빛스틸 사내 규격)
- 한 항목이라도 범위를 벗어나면 **불합격**, 한계값의 3% 안쪽이면 **근접**, 나머지 **합격**
- 한계값과 같으면 범위 안 (합격 쪽)

## 답 형식
- 표: 코일 · 강종 · 판정 · 이탈 또는 근접 항목 (값 / 규격)
- 불합격을 맨 위에 · 근거 없는 추정 금지 · 모르면 「확인 필요」

## 하지 않는 것
- 출하 승인은 사람이 한다 · 승인 도구는 부르지 않고 승인 후보와 근거만 보고
- `sim/` 의 시뮬레이터 코드와 규격 파일은 고치지 않는다
