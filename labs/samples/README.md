# 업무 분야별 샘플 데이터 (가상)

사전 과제로 생각해 온 주제와 가장 가까운 폴더를 골라, 메타 하네스 실습(Ch7 · Ch8)의 예시 입력으로 쓴다.
실제 운영 데이터는 쓰지 않는다. 내 업무와 다르면 이 형식을 본떠 가상 데이터를 만들어 달라고 Claude에게 요청한다.

| 폴더 | 분야 | 자료 |
|---|---|---|
| mes/ | 철강 생산관리 · MES | 장애 로그 · 생산 실적 |
| process_control/ | 공정 제어 시스템 | 알람 로그 · 알람 규칙 |
| equipment/ | 설비관리 · 스마트팩토리 | 정비 이력 · 진동 측정 |
| battery/ | 배터리 소재 생산 | LOT 품질 · 출하 기준 |
| logistics/ | 원료 · 구매 · 물류 | 운송비 청구 · 정산 기준 |
| erp_sap/ | 협업 · 경영지원 (SAP) | 전표 · 예산 실적 |
| sales_dx/ | 기획 · 영업 DX | 프로젝트 현황 · 고객 문의 |
| smarthome/ | 건설 · 스마트홈 | 장애 티켓 |
| security/ | 안전 · 보안 · 품질 | 출입 기록 · 점검 항목 |
| ai_platform/ | 생성형 AI · 자동화 플랫폼 | 문의 티켓 · RPA 로그 |
| ai_modeling/ | AI 모델링 · AI 과제 | 실험 기록 |

각 폴더의 `하네스_주제_예시.md`: 반복 업무 · 확인 방법 · 유형 (업무 처리 3종 중 하나는 개발형)
