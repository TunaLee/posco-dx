# 이번 변경 (PR #187) · 운송비 정산 서비스 1차

새 모듈 18개: 정산 · 일괄 검증 · DB 조회 · 페이지 · 정산 기간 · 외부 동기화 · 할증 규칙 · 내보내기 · 시작 · 캐시 · 보고서 · CSV 읽기 · 검증 · 표시 형식

정산 기준
- 정산액 = 거리 × 중량 × 톤km 단가, **원 미만 절사**
- 청구액과 정산액 차이가 **1%를 넘으면** 이의 제기 (정확히 1%는 정상)
- 정산 기간은 **월 단위** (YYYY-MM, 1월 = 01)
- 청구 CSV의 숫자에는 천 단위 쉼표가 들어올 수 있음 (예: "1,234")
- 내보낸 CSV는 엑셀로 연다
