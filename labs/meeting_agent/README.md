# 내 업무 에이전트 — 회의록 정리

> ※ 회의 내용 · 사람 · 숫자는 모두 실습용 가상 자료입니다.

`원본/` 의 회의록을 읽고 **할 일 · 담당자 · 기한** 을 정리하는 에이전트를 Claude Code 와 함께 만든다.
하네스(`.claude/`, `CLAUDE.md`)는 처음엔 없다 — 차시마다 하나씩 붙인다.

| 차시 | Claude 에게 (짧게) | 생기는 것 |
|---|---|---|
| 3-3 | 회의록 하나를 내 노션에 붙여 넣기 → 「노션 MCP(https://mcp.notion.com/mcp)를 연결해 줘」 → 「노션에서 11/10 주간 회의 페이지 찾아서 할 일만 뽑아 줘」 | 노션 읽기 |
| 3-4 | 「원본은 읽기만 · 결과는 out/ 에 · 이 규칙을 CLAUDE.md 로 정리해 줘」 | `CLAUDE.md` |
| 3-5 | 「11/10 회의록 정리해 줘」 → 「방금 결과에서 좋았던 것 · 바꿀 것을 반영해 회의록 정리 Skill 로 만들어 줘」 | `.claude/skills/meeting-notes/` |
| 3-6 | 「팀장이 허락했어 · 11/3 원본의 「휴대촌」 오타를 고쳐 줘」 → 되돌리기 → 「원본 폴더는 못 고치게 Hook 으로 막아 줘」 | `.claude/settings.json` · `hooks/` |
| 3-7 | 「회의록 정리 결과를 원본과 대조해 검토하는 Sub Agent 를 만들어 줘」 → 「11/5 · 11/10 회의록 정리하고 검토까지 해 줘」 | `.claude/agents/notes-checker.md` |

- 결과는 `out/` 에 남는다. 원본은 고치지 않는다.
- 11/3 원본의 「휴대촌」은 3-6 실습용으로 일부러 심은 오타다.
- 막히면 `solution/` → `dot_claude/` 를 `.claude/` 로, `CLAUDE.md` 를 이 폴더 맨 위로 복사.
- 회사 노션 · 슬랙이 MCP 연결을 막아 두었으면 이 폴더의 파일로 그대로 진행한다.
