# 내 업무 에이전트 — 회의록 정리

> ※ 회의 내용 · 사람 · 숫자는 모두 실습용 가상 자료입니다.

`원본/` 의 회의록을 읽고 **할 일 · 담당자 · 기한** 을 정리하는 에이전트를 Claude Code 와 함께 만든다.
하네스(`.claude/`, `CLAUDE.md`)는 처음엔 없다 — 차시마다 하나씩 붙인다.

요청 문장은 직접 쓴다. 차시마다 **요청에 들어갈 것**(목표 · 입력 · 산출물 · 하지 말 것)만 정해 두었다.
판단 기준(기한 없는 할 일 · 막을 것 · 검토 기준)은 사람이 정하고, 파일은 Claude 가 쓴다.

| 차시 | 내가 정할 것 | 생기는 것 |
|---|---|---|
| 3-2 | 설계 질문 7칸을 먼저 채우고 빈 칸만 Claude 에게 묻기 | `out/설계서.md` |
| 3-3 | 읽을 노션 페이지 · 뽑을 내용 · 막을 쓰기 도구 | 노션 읽기 |
| 3-4 | 원본 · 결과 폴더 규칙 | `CLAUDE.md` |
| 3-5 | Skill 없이 받은 결과에서 바꿀 것 3개 · 기한 없는 할 일 처리 | `.claude/skills/meeting-notes/` |
| 3-6 | 막을 폴더 · 도구 · 막혔을 때 돌려줄 이유 | `.claude/settings.json` · `hooks/` |
| 3-7 | 검토 기준 3개 · 검토 Agent 가 돌려줄 것 | `.claude/agents/notes-checker.md` |

- 결과는 `out/` 에 남는다. 원본은 고치지 않는다.
- 11/3 원본의 「휴대촌」은 3-6 실습용으로 일부러 심은 오타다.
- 막히면 `solution/` → `dot_claude/` 를 `.claude/` 로, `CLAUDE.md` 를 이 폴더 맨 위로 복사.
- 회사 노션 · 슬랙이 MCP 연결을 막아 두었으면 이 폴더의 파일로 그대로 진행한다.
