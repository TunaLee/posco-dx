.claude/settings.json (hooks 부분)
"PreToolUse": [{ "matcher": "Bash|Write|Edit",
  "hooks": [{ "type": "command", "command": "python3 .claude/hooks/guard.py" }] }]
.claude/hooks/guard.py
import json, sys
e = json.load(sys.stdin)            # 도구 이름 · 입력
i = e.get('tool_input', {})
bad = ['rm -rf', 'push --force']
if any(b in i.get('command', '') for b in bad) \
   or i.get('file_path', '').endswith('.env'):
    print('차단: 위험 명령 · 비밀 파일', file=sys.stderr)
    sys.exit(2)                     # 2 = 막고 이유를 Claude에게

import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, ResultMessage

options = ClaudeAgentOptions(
    system_prompt=open('harness_prompt.md').read(),
    allowed_tools=[],          # 자동 허용할 도구
    setting_sources=[],        # 내 PC 설정 영향 끄기
    max_turns=5,
)

async def main():
    async for m in query(prompt=open('specs/S03.txt').read(), options=options):
        if isinstance(m, ResultMessage):
            print(m.result, m.total_cost_usd, m.usage)

asyncio.run(main())

커스텀 도구
from claude_agent_sdk import tool, create_sdk_mcp_server

@tool('get_price', '품목 · 규격의 단가를 찾는다', {'item': str, 'spec': str})
async def get_price(args):
    hits = lookup(args['item'], args['spec'])   # 단가표
    return {'content': [{'type': 'text', 'text': hits}]}

price = create_sdk_mcp_server(name='price', version='1.0.0', tools=[get_price])
options = ClaudeAgentOptions(
    mcp_servers={'price': price},
    allowed_tools=['mcp__price__get_price'],
)

LLM-as-judge 채점 기준

lab4_eval_design/judge_prompt.md
너는 사양서 추출 결과 채점자다.
[사양서] {spec}
[추출 JSON] {answer}

1~5점으로 채점하고 JSON으로만 답한다.
- 정확도: 필드 값이 원문과 맞는가
- 근거 충실도: 근거에 없는 내용을 만들었는가 (만들면 1점)
- 형식: 단위 · null 규칙을 지켰는가
{"accuracy": n, "grounded": n, "format": n, "reason": "..."}
