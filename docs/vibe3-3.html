연결 상태 확인

Connected연결됨 · 바로 사용
Needs authentication로그인 필요 · /mcp 에서 로그인
Failed to connect연결 실패 · 주소 · 네트워크 확인
터미널 · 연결 관리 명령
claude mcp list          # 등록한 서버와 상태
claude mcp get notion    # 한 서버의 설정 보기
claude mcp remove notion # 연결 지우기
/mcp                     # 대화 안 · 상태 확인 · 로그인
실패 표시 그 서버에 연결하지 못했다는 뜻 · 목록 명령이 실패한 것은 아님

쓰기 도구 막기 예

.claude/settings.json
{
  "permissions": {
    "deny": [
      "mcp__notion__notion-update-page",
      "mcp__notion__notion-delete-pages",
      "mcp__notion__notion-create-pages"
    ]
  }
}
이름 규칙 mcp__서버이름__도구이름 · mcp__notion__* = 노션 도구 전부 · 판단 순서는 3-6
